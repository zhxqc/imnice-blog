## 模型 / 产品

### 1. Google · Gemini API Computer Use 正式 GA（2026-10-30）
- **背景：** 浏览器/移动/桌面 UI 自动化此前多处于预览；与 OpenAI / Anthropic 的 computer-use 能力正面对照。
- **发生了什么：** Gemini API changelog 宣布 **Computer Use** 在 **Interactions API** 与 **GenerateContent API** 升至 GA。文档列支持模型含 Gemini 4 Argon、3.8 Flash（推荐）等；按所用模型 token 计价（未见单独 Computer Use 附加费条目）。仍需客户端执行动作，文档继续强调监督与敏感场景风险。
- **为什么重要：** 从预览进入生产可用状态，降低「能否上生产 Agent 环」的门槛；仍要把沙箱与权限开关当作默认设计，而非可选装饰。
- **来源：** [Gemini API changelog](https://ai.google.dev/gemini-api/docs/changelog) · [Computer Use 文档](https://ai.google.dev/gemini-api/docs/computer-use) · [AIHOT](https://aihot.news/items/qit1hgequ8pknedqqvuei5wfh)

### 2. Anthropic · Claude Code 2.1.314：默认可拦「工作目录外写入」（2026-10-30）
- **背景：** 无人值守 / CI Agent 场景下，写路径越界是高发事故面；当日 Cursor 供应链事件同主题加压。
- **发生了什么：** Release **v2.1.314** 新增设置 `permissions.blockWritesOutsideWorkingDirectories`——启用后 Write / Edit / NotebookEdit 在任何权限模式下拒绝工作目录外路径；另含 gateway / VS Code 等修复。官方亦建议受 Cursor 恶意扩展影响者升级到该版 Claude Code for VS Code。
- **为什么重要：** 把「权限边界」从提示词约定推成产品开关；与扩展市场信任链问题对照，说明 Agent 安全要同时管安装源与写路径。
- **来源：** [GitHub Release v2.1.314](https://github.com/anthropics/claude-code/releases/tag/v2.1.314)

### 3. Anthropic · Claude Max 更名 Max / Ultra；认证 Ultra 取消 5 小时限额（约 2026-10-31）
- **背景：** 重度订阅者长期受「5 小时滚动限额」约束；套餐名 Max 5x / 20x 对外沟通成本高。
- **发生了什么：** Anthropic 员工（Ado Kukic）确认：Max 5x → **Max**（$100/月）、Max 20x → **Ultra**（$200/月），**价格不变**。即日起多数老订阅者的认证 Ultra 账号**取消 5 小时限制**；新账号保留临时限制以防欺诈滥用；**周限额不变**。
- **为什么重要：** 对 Ultra 重度用户是实质可用性提升；选型时仍需盯周限额与新账号临时限制，勿误读为「无限」。
- **来源：** [X / Ado Kukic](https://x.com/adocomplete/status/2116224220539883992) · [AIHOT](https://aihot.news/items/pd3dehdyyhzkyrjsw4b6bmcyj)

- **为什么重要：** 供应链击穿的是「官方名义扩展」信任，而非单点漏洞；企业需清点是否装过 2.1.312/2.1.313，并评估第三方扩展上架审核缺口。
