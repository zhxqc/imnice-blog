## 模型 / 产品

### 1. MiniMax · M3.1 Flash（2026-10-19）
- **背景：** Agent 多步调用把「单次推理价格」放大成任务总成本；Flash 档继续比拼速度与任务成本。
- **发生了什么：** MiniMax 正式发布 **M3.1 Flash**，确认此前匿名模型 **Space Bunny**（宣称处理超 **200 万亿** token）为其早期版本。官方称在线推理提速近 **3 倍**、Agent 用量成本降约 **70%**；日常输出可达 **200+ TPS**（P50 约 **170+**）。厂商披露：DeepSWE v1.1 **73.7%**、OSWorld V2 **61.7**、CyberGym **82%** 等。定价：**$0.15 / $0.60 / $0.015**（输入/输出/缓存，每百万 token）。API / M Plan / MiniMax Code 可用；**权重稍后开源**；Pro 预告后续。
- **为什么重要：** 与 DeepSeek Flash 同价位段正面竞争 Agent/编码任务；Space Bunny 身份落地方便复盘此前公开流量。
- **开放方式 / 规模 / 许可证：** API 现已可用；总参量等细节见开发者文档（二手称约 428B 量级）；权重 **官方未披露发布日**；许可证待权重稿。
- **来源：** [MiniMax 官方](https://www.minimax.io/blog/minimax-m31f) · [AIHOT](https://aihot.news/items/wrnv8dd428iozlj5xax99zbmj)

### 2. Inception Labs · Mercury 3（扩散式 LLM，2026-10-19）
- **背景：** 扩散语言模型能否扩到与自回归「快档」正面竞争，是过去一年开放问题。
- **发生了什么：** Inception 发布 **Mercury 3**：官方称多项基准对标或超过 **GPT-6 Luna**、**Claude Haiku 5.5**，速度约 **1,068 tok/s**（NVIDIA GPU），上下文 **1M**（相对 Mercury 2.5 的 260K），参数量相对 Mercury 1 扩大 **40×+**。标价 **$0.20/$0.70** 每百万输入/输出，上线期五折 **$0.10/$0.35**。已上 Inception API、**OpenRouter**、Baseten、Vercel；兼容 OpenAI API。
- **为什么重要：** 「扩散也能扩规模」的产品化证据；对语音、浏览器 Agent、实时搜索等延迟敏感场景是新选型。
- **开放方式 / 规模 / 许可证：** 闭源 API；精确参数量 **官方未披露**（仅相对倍数）。
- **来源：** [Inception 官方](https://www.inceptionlabs.ai/blog/introducing-mercury-3) · [OpenRouter / X](https://x.com/OpenRouter/status/2112225779782398131)

### 3. OpenAI · 低资源编程语言能力与 MultiLangBench（2026-10-19）
- **背景：** COBOL 等语言训练语料少，却仍承载银行/ATM/气象等关键系统；客户反馈编码模型在这类语言上偏弱。
- **发生了什么：** OpenAI 官博介绍最新模型在 **COBOL、Fortran、Visual Basic、OCaml** 等语言上的构建与**行为保持迁移**能力，发布两套自建评测：**(1) MultiLangBench**——用 20 种语言从零实现 SQLite 兼容引擎并用同一测试集打分；**(2) COBOL→C++/Java/Kotlin/Python/Rust 迁移**，要求可观察输出字节级一致。厂商披露：GPT-6 Astra 在 MultiLangBench 平均通过率 **87.4%**（对比 GPT-5.6 Sol **26.8%**）；GPT-6.1 Sol 在 COBOL 迁移低推理档 **86.6%**（对比 5.4%），高推理档 **97.9%**。MultiLangBench **开源到 GitHub**。
- **为什么重要：** 把「遗留系统现代化」从营销叙事落到可复现评测；数字均为**官方测试**。
- **来源：** [OpenAI](https://openai.com/index/low-resource-programming-languages)

### 2. 斯坦福 HAI · 医疗 AI「能干什么」三件套基准（2026-10-19）
- **背景：** 医考选择题接近满分 ≠ 能在 EHR 里把活干完；需要执行接地（execution-grounded）评测。
- **发生了什么：** 斯坦福团队总结三年工作：**MedHELM**（5 大类 121 任务）显示临床决策支持与行政管理得分最低；**PhysicianBench**（100 个长程临床任务）最佳 **GPT-5.5** 单次完成约 **46%**，三次全成功仅约 **28%**；**HealthAdminBench**（授权/申诉等行政）最佳 **Claude Opus 4.6** 端到端约 **36.3%**。失败主因：跨文档/系统传信息丢失、写对计划却不下医嘱等。合成数据、代码与排行榜开放。
- **为什么重要：** 给「医疗 Agent  readiness」一个可引用的残酷基线——最好也完成不了一半。
- **来源：** [Stanford HAI](https://hai.stanford.edu/news/measuring-what-medical-ai-can-actually-do)

## 论文

窗口对应 arXiv listing **Monday, 19 October 2026**（美东周一晚间投放，北京周二清晨可读）。以下均为**首次提交 v1**；精选与 Agent / MCP / harness / 医疗安全相关条目。

### 1. MS-Eval: Benchmarking Sub-Agent Delegation and Orchestration in MCP-Intensive Working Scenarios（首次提交）
- **核心贡献：** 评测 LLM Agent 在 MCP 密集场景下的**子代理委派与编排**能力。
- **与已有方法区别：** 面向真实工作流中多子任务并行/委派，而非单线程工具调用。
- **代码/数据：** 摘要未在 list 页完整声明 → 以 PDF/项目页为准。
- **链接：** [arXiv:2610.22869](https://arxiv.org/abs/2610.22869)

### 2. Harness-Delta Attribution: Dissecting Gains From Harness Evolution（首次提交）
- **核心贡献：** 在**固定权重**模型上，把收益归因到 harness（提示、skills、工具、编排代码）演化。
- **为什么重要：** 直接服务「改 harness 还是换模型」的工程决策。
- **链接：** [arXiv:2610.22466](https://arxiv.org/abs/2610.22466)

### 3. Structured Authority Injection: Persistent Human Control for LLM Agents via Typed MCP Overrides（首次提交）
- **核心贡献：** 经类型化、schema 校验的 MCP 工具调用注入 Constraint/Priority/Strategy 级覆盖，并在每轮提示前维护排序后的权威上下文，缓解自由文本 override 歧义与权威衰减。
- **实验：** 9 个 LLM × 8 场景；称可降低歧义解释与权威衰减（最强模型提示开销最多降约 38%，跨模型差异大）。
- **链接：** [arXiv:2610.22373](https://arxiv.org/abs/2610.22373)

### 4. GatewayBench: Unified Capability and Security Evaluation Platform for MCP Gateways（首次提交）
- **核心贡献：** 统一评测 MCP **网关**能力与安全。
- **链接：** [arXiv:2610.23449](https://arxiv.org/abs/2610.23449)

### 5. The Model Knows Better: Defending Medical Multi-Agent Systems Against Prompt Injection（首次提交）
- **核心贡献：** 针对医疗多 Agent 会诊场景的提示注入防御。
- **链接：** [arXiv:2610.22594](https://arxiv.org/abs/2610.22594)

### 6. Self-Evolving Coding Agents via Harness-Policy Optimization（首次提交）
- **核心贡献：** 联合优化策略模型与环境交互 harness，使编码 Agent 自演化。
- **链接：** [arXiv:2610.22791](https://arxiv.org/abs/2610.22791)
