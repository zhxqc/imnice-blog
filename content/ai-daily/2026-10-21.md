## 模型 / 产品

### 1. DeepSeek · DeepInfer 开源（Apache-2.0，2026-10-20）
- **背景：** V4.1-Flash 权重与 FlashMLA / DeepGEMM / DeepEP 等底层库已陆续放出；社区缺的是可复现的「整机」离线推理栈。
- **发生了什么：** 开源 DeepInfer——支撑 DeepSeek-V4.1-Flash 生产推理的高性能**离线**框架。特性含优化 kernel、Attention DP / MoE EP、投机解码（DSpark）、批不变推理、确定性采样、结构化输出等；硬件支持 **NVIDIA SM100** 与 **华为 Ascend 950**。明确**不含**完整在线服务所需的 KV-cache、Prefill/Decode 分离与跨副本负载均衡；另同步开源 tokenization 组件 deepseek-recipe。
- **为什么重要：** 降低自建 DeepSeek 服务的工程门槛与成本；Ascend 路径对非美供应链有信号意义。注意这是引擎核心而非开箱 SaaS；吞吐数字目前多为厂商自测。
- **开放方式 / 许可证：** Apache-2.0；默认权重 DeepSeek-V4.1-Flash-1017（MIT）；构建需 Python 3.12、CUDA 13 / CANN 9.2 等。
- **来源：** [GitHub deepseek-ai/DeepInfer](https://github.com/deepseek-ai/DeepInfer)

### 2. Google × Meta · TorchTPU（PyTorch 原生 TPU 后端，2026-10-20）
- **背景：** TPU 长期偏 JAX/XLA；PyTorch 用户迁移摩擦大，旧 PyTorch/XLA 难跟 eager 与生态节奏。
- **发生了什么：** 开源 TorchTPU：把 `.to("cuda")` 改为 `.to("tpu")` 即可跑通现有工作流；支持 eager / `torch.compile`、分布式原语，并联动 **vLLM-TorchTPU、SGLang-TorchTPU、TorchTitan、Ray、Hugging Face**（含 `device_map="tpu"`）。宣称对约 5000 个热门 HF 模型做过 out-of-box 验证（厂商披露）。
- **为什么重要：** 训练/推理硬件选择进一步松绑「绑死 CUDA」；对企业与开源栈是基础设施级选项。
- **来源：** [PyTorch Blog](https://pytorch.org/blog/introducing-torchtpu/) · [Google Cloud Blog](https://cloud.google.com/blog/topics/ai-infrastructure/torchtpu-is-now-open-source-run-native-pytorch-on-tpus)

### 3. Meta · Muse Spark Open 上线 Fireworks（Day-0 serverless，2026-10-20）
- **背景：** Meta 开源权重路线持续加码长上下文 Agent/编码；Prometheus 超集群等基建叙事昨日已覆盖。
- **发生了什么：** **Muse Spark Open**——约 **816B** 参数 MoE、每 token 激活约 **42B**、上下文 **1M**——在 Fireworks 以 US serverless / Zero Data Retention 上线。第三方/索引披露：Vals Legal Agent 榜约 **25.4%**（对比 Claude Opus 5 约 6.7%）；金融/临床文档等专业基准表现强（多为第三方或厂商索引，注意 harness 差异）。
- **为什么重要：**「美国开源权重 + 合规托管」组合对受监管行业试验有吸引力；长会话编码/Agent 场景直接可调用。
- **开放方式：** 开源权重 + Fireworks API；定价见模型页。
- **来源：** [Fireworks](https://fireworks.ai/blog/meta-muse-spark-open)

### 4. Mistral · Voxtral 3 语音 Agent 栈（2026-10-20）

- **为什么重要：** 欧洲厂商给出「主权部署友好」的端到端语音 Agent 产品路径。
- **来源：** [mistral.ai/news/voxtral-3](https://mistral.ai/news/voxtral-3/)

### 6. ChatGPT · Locked Chats（2026-10-20）
- **背景：** 共享设备上对话历史易被侧栏/搜索看见。
- **发生了什么：** 可将敏感对话移出常规历史与搜索，用账户 PIN 或生物识别解锁；锁定会话内新消息不更新常规记忆。面向 Free 至 Enterprise/Edu 等套餐逐步放开。
- **为什么重要：** 消费级隐私控制补齐；非模型能力，但是高频产品更新。
- **来源：** [OpenAI Help](https://help.openai.com/en/articles/20001411-using-locked-chats-in-chatgpt)

### 7. Modal · Sticky Sessions（2026-10-20）
- **背景：** Serverless 默认请求可漂移到不同容器；语音 Agent、共享房间、游戏需要会话亲和。
- **发生了什么：** 在 Modal Servers 上推出 Sticky Sessions（`@modal.sessioned()`），同一会话请求固定到同一容器，并按会话做扩缩容。
- **为什么重要：** 让「有状态实时 Agent」在 serverless 上可产品化，而不必 `max_containers=1`。
- **来源：** [Modal Blog](https://modal.com/blog/serverless-routing-made-sticky)

### 8. Databricks · MemCurrent 生产级 Agent 记忆（2026-10-20）
- **背景：** 企业 Agent 在质量与成本之间难两全；「塞满历史」又贵又脏。
- **发生了什么：** 介绍 MemCurrent：情景记忆 + 派生记忆；插件 / 工具 / 离线 dreaming 三路读写。内部基准称相对无记忆通过率约 **3×**，同时约 **-31% tokens、快 26%**（厂商披露）。已用于 Agent Bricks Memory 与 Genie。
- **为什么重要：** 给出可对照的生产记忆架构与消融，而非只谈向量库口号。
- **来源：** [Databricks Blog](https://www.databricks.com/blog/memcurrent-designing-persistent-memory-production-agents)
