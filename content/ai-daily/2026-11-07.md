## 模型 / 产品

### 1. Anthropic · 智能体记忆的组件：笔记、显著性与 dreaming【头条·研究】
- **背景：** Agent 跨会话留存什么、何时写、如何纠错，正在从「塞进 system prompt」变成可拆解的系统设计问题。
- **发生了什么：** Anthropic（**2026-11-06**）发布工程研究长文，把 agent memory 定义为可跨会话读取的经验知识（排除改权重、单会话 in-context、compaction）。核心机制包括：会话内写**记忆笔记**并判断显著性；空闲期 **dreaming** 对照 transcript 纠错、建 wiki、把要点提升到每会话预注入层。评测覆盖 CL-Bench 数据库任务、Pokémon（Fable 5 等用更少文件走得更远）、Stainless 约 35 万文件语料上 wiki 随 dreaming 轮次达标率约 **13%→48%**、Harvey LAB 等（均为作者披露）。Claude Code auto memory 仅注入 `MEMORY.md` 前 **200 行 / 25KB** 作索引。
- **为什么重要：** 给出可迁移的「写—睡—纠—索引」分工与失败案例（错误笔记导致 Mt. Moon 循环）；对自建记忆系统比口号式「长期记忆」更可操作。
- **来源：** [Anthropic · Components of agent memory](https://www.anthropic.com/research/components-of-agent-memory)

### 2. Cursor · Voice Chat：与 Agent 实时语音通话【头条·竞品】
- **背景：** 昨报 Live Apps 把 Agent 推到「可分享部署」；本窗进一步把交互模态扩到语音。
- **发生了什么：** Cursor Changelog（**2026-11-06**）上线 Voice Chat：Agents Window / IDE / Web / iOS 均可双向通话；可口述改动、追问进度、在多 worker 间切换；编码 Agent 播报短进度而非整段书面回复。底层 **Grok Voice**（Ara/Eve/Leo/Rex/Sal 等音色）；Privacy Mode 下零数据留存。明确区别于听写（原 Voice Mode / Cmd+Shift+Space）。
- **为什么重要：** 竞品优先关注项——降低「盯着 diff 打字」的摩擦，尤其适合并行云端 Agent 与移动端跟进。
- **来源：** [Cursor Changelog · Voice Chat](https://cursor.com/changelog/voice-chat)

### 3. Meta · Muse Wonder 特化模型进入 Muse / Meta AI【产品】
- **背景：** 前沿「个人超智」模型若只停留在小流量，消费侧助手仍吃不到记忆与目标坚持能力。

- **为什么重要：** 把研究侧能力下沉到大规模助手产品；数字均为官方评测，需外部复核。
- **来源：** [Meta AI Research](https://research.meta.ai/blog/specialized-models-for-muse-and-metaai)

## 论文

（口径：arXiv cs.AI / cs.CL 等 `new` 列表，对应 **2026-11-06** 新挂牌；优先 Agent 评测 / 能力封装 / 成本归属 / 授权 / MCP 安全。）

### 1. Closed-Loop Agent Evaluation（arXiv:2611.07051）
- **核心贡献：** 已上线 Agent 的闭环评测方法：四层分析 + 七组件 + 内外双环；证据与版本化规则优于整体打分（ICC **0.86 vs 0.81**，κ **0.81 vs 0.63**）。
- **来源：** [arXiv:2611.07051](https://arxiv.org/abs/2611.07051)

### 2. Don’t Prompt Your Agents. Equip Them: Skillware（arXiv:2611.07652）
- **核心贡献：** 用版本化能力包（契约、确定性代码、指令、测试）装备 Agent，而非提示驱动写代码；23 模型 / 368 条件称最高约 **84.8%** token、**97.3%** 成本下降。
- **来源：** [arXiv:2611.07652](https://arxiv.org/abs/2611.07652) · [代码声明](https://github.com/arpahls/skillware)

### 3. The Two-Ledger Model（arXiv:2611.06989）
- **核心贡献：** 多 Agent 跨云「结算 FOCUS 账本 + 调用归属账本」；仿真称成本覆盖 **>99%**，中途门控可降 p99 交易成本最高约 **61%**。
- **来源：** [arXiv:2611.06989](https://arxiv.org/abs/2611.06989)

### 4. Trust Responsive Runtime Authorization / TRAP（arXiv:2611.06995）
- **核心贡献：** 把信任、稳定、情境风险合成授权就绪分，非对称升降级；渐变劣化时「限制」优势可能消失。
- **来源：** [arXiv:2611.06995](https://arxiv.org/abs/2611.06995)

### 5. Agent-Native Primitives / HEELO（arXiv:2611.07461）
- **核心贡献：** 「最后一公里」——原语内嵌如何应用资源；Terminal-Bench 4.0 同骨干 **37.3%→55.5%**（作者披露）。
- **来源：** [arXiv:2611.07461](https://arxiv.org/abs/2611.07461)

### 6. MCPHallu（arXiv:2611.07508）
- **核心贡献：** MCP 场景幻觉诊断基准（推理/执行/记忆）；14 模型平均 **0.642**；Unreachable Goal 子类尤其难。
- **来源：** [arXiv:2611.07508](https://arxiv.org/abs/2611.07508)
