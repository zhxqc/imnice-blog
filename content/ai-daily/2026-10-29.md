## 模型 / 产品

### 1. DeepMind · Gemini 4 Carbon：网络安全与长程 Agent 前沿（2026-10-28）
- **背景：** Argon 两周前刚推，Carbon 把「编码/Agent」与「安全防御」并列为同一代 frontier 的主卖点，且刻意先给防御方试水。
- **发生了什么：** Google DeepMind 发布 Gemini 4 Carbon，自称最强前沿模型。公开基准（**厂商披露**，官方称无防护评估）：SEC-bench Pro **88.2%**（找漏洞）、ExploitGym **54.8%**（利用验证）、CWE-bench **71.0%**（打补丁）；Artificial Analysis Intelligence Index v5.0 **59** 登顶。内部称安全代码生成成功率相对 Argon **>2×**，间接提示注入（Gray Swan IPI）攻击成功率 **0.0%**。WebDev Arena **+89 Elo** 至约 **1768（#4）**。正参与美国政府自愿预发布测试；本周起向部分 cyber 防御方开放，再经 Fairwind 扩至可信伙伴，再面向开发者/企业/消费者。入门价与 Argon 相同：**$2 / $10** 每百万 in/out tokens（缓存输入约 **95%** 折扣）；入门期后升至 **$4 / $20**。**非开源权重；开放方式/规模官方未披露完整参数量。**
- **为什么重要：** 把「长程工程 Agent」与「自动找洞—验证—打补丁」绑成同一产品故事，并采用防御方优先的发布节奏，直接影响安全团队与编码 Agent 选型。
- **来源：** [DeepMind 官方](https://deepmind.google/blog/gemini-4-carbon-our-next-frontier-model/) · [AIHOT](https://aihot.news/items/fjeloaahylonpc0pv5tduusud)

### 2. Microsoft · Copilot harness 经 Foundry 对外开放（2026-10-28）
- **背景：** 企业要「多模型」往往卡在自建 harness（编排、工具、沙箱、成本与评测）而不是缺某一个 API。
- **发生了什么：** Microsoft 宣布将 GitHub 工程团队打造、已在公司内统一的 **Copilot harness** 通过 **Microsoft Foundry** 提供给开发者与企业。官方称该 harness 已驱动 Copilot Code、Copilot Studio、GitHub Copilot 应用与 CLI、VS Code 等；支持 **20+** 前沿模型与 BYOK，开放标准如 **MCP** 与 agent skills/plugins；运行时近期移植到 **Rust** 以降低会话开销与首 token 时延（**厂商披露**）。可下载 SDK 或在 Foundry 云托管运行；仍允许自带其它 harness。
- **为什么重要：** 把「微软/GitHub 自家 Agent 运行时」产品化，降低多模型 Agent 落地成本，也强化 Foundry 作为企业 Agent 控制面的叙事。
- **来源：** [Microsoft 官方博客](https://blogs.microsoft.com/blog/2026/10/28/introducing-the-microsoft-copilot-harness-unlocking-the-potential-of-truly-multi-model-agentic-work/) · [AIHOT](https://aihot.news/items/tdp7qmrh74fdfarxbi4jaoc6v)

### 3. Cartesia · H-Net 扩缩律：字节级层级网络 vs BPE（2026-10-28）
- **背景：** Tokenizer 仍是语言建模里少数「人工先验」环节；字节级端到端学习被视为下一档数据效率杠杆。
- **发生了什么：** Cartesia 发布 H-Net 系列博文第一篇：在严格匹配的 1-stage H-Net vs BPE Transformer 扩缩阶梯上，验证集约 **1.28×** 算力效率，下游评测约 **2×**；代码任务中位约 **2.04×**，训练分布外编程语言中位约 **3.10×**（如 Prolog **5.37×**）（**厂商披露**）。更大的 2-stage 字节 H-Net 对标 SmolLM3 配方时，官方称以约 **1T** vs **~11T** tokens 达到相近平均分（算力/字节匹配口径下约 **10×** 数据效率）。架构与权重发布计划写「计划开源部分」，**具体许可证官方未在文中最终敲定**。
- **为什么重要：** 给「扔掉 BPE、学动态分块」提供可核对的扩缩实验，对代码/OOD 语言尤其敏感的团队值得跟读第二篇机制分析。
- **来源：** [Cartesia 官方](https://www.cartesia.ai/blog/from-tokens-to-bytes-part-1) · [AIHOT](https://aihot.news/items/ctuk7r4h4qbyyligi680s7gtr)
