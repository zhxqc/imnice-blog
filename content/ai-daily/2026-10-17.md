## 模型 / 产品

### 1. Reflection · Beam（开源权重）
- **背景：** 继本周 Meta Muse Spark Open、NVIDIA Nemotron 之后，美国新实验室 Reflection 放出首个可自托管的大规模开源权重模型，直接对标编码与长程 Agent。
- **发生了什么：** 2026-10-16 在 Hugging Face 发布 **Beam**（`reflection/Beam-1.0-501B-A23B`）：稀疏 MoE，**501B** 总参 / **23B** 激活，文本模态，**1M** 上下文；BF16 / FP8 / NVFP4 与 DFlash2 投机解码 draft 头一并提供。Artificial Analysis 测得 Intelligence Index **30**（美国开源第二，全球开源约第十）；AutomationBench-AA **48.5%**，Terminal-Bench 4.0 仅 **3.0%**（弱项）。vLLM Day-0 支持并在 Blackwell 上做融合优化；Ollama Cloud 限时免费 + 零数据保留。自研 Mirror CLI harness 同步开源友好。
- **为什么重要：** 把「美国开源 Agent/编码基座」从 Muse 一家扩展到第二家量级选手；企业可对照 Muse（多模态）与 Beam（文本+编码）做自托管选型。
- **开放方式 / 规模 / 许可证：** 开源权重 + 多云托管 + Reflection API；规模见上；**Apache 2.0**。
- **来源：** [Reflection Blog](https://reflection.ai/blog/beam-is-available) · [HF Blog](https://huggingface.co/blog/reflection-beam) · [Artificial Analysis](https://artificialanalysis.ai/articles/reflection-beam) · [vLLM](https://vllm.ai/blog/2026-10-16-reflection-beam) · [AIHOT](https://aihot.news/items/a3roan35e4kghyxdjffek1hop)

## 研究 / 论文 / 报告

### 1. Anthropic · How employment is changing at Anthropic（2026-10-16）
- **核心贡献：** 用内部雇佣、agent 遥测、产出与面试记录，量化前沿实验室「人机共工」对初级岗与用人标准的冲击。
- **关键数字：** 至 2026-08，交互式 AI agent 工时约为员工 **6×**；技术部门初级员工占比 21%→14%，初级技术招聘占比 **27%→9%**；工程师采纳 coding agent 后提交量显著上升（厂商内部因果估计）。
- **为什么重要：** 少见的一手「实验室即用工现场」证据，直接服务 coding Agent 产品的组织影响讨论。
- **代码/数据：** 报告与图表公开；原始内部数据未开放。
- **来源：** [Anthropic Research](https://www.anthropic.com/research/employment-at-anthropic)

### 2. Anthropic · The AI expectations gap（2026-10-16）
- **核心贡献：** 对比美国成人代表样本（N=10,980）与 Anthropic 员工对能力、生产率与失业预期。
- **关键数字：** 2030 年前 AI 能做出诺贝尔级发现：公众 **39%** vs 员工 **91%**；员工平均预期 AI 能完成其当前工作的 **75%**，美国工人 **28%**。
- **为什么重要：** 把「实验室内认知」与「公众预期」钉成可引用差距，校准媒体与政策叙事。
- **来源：** [Anthropic Research](https://www.anthropic.com/research/ai-expectations-gap)

### 3. Anthropic · Claude reveals ECDSA curve origins（2026-10-16）
- **核心贡献：** 内部研究模型在约半小时内还原 NIST P-192/224/256/384/521 等种子：非哈希口令，而是 C 库 **`lrand48`** 以 Unix 时间戳初始化的输出（如 P-256 需 **1842** 次迭代）；附可复现代码。**不是**密码学破解，反而降低「故意后门选参」嫌疑。
- **代码/数据：** 页面提供复现脚本；$36,864 赏金捐 Internet Security Research Group。
- **来源：** [Anthropic Research](https://www.anthropic.com/research/ecdsa-curve-origins)

### 4. Anthropic / Harvard · Discovering SOTA quantum circuits with LLMs（论文 + 博客，披露 2026-10-16）
- **类型：** arXiv 首次提交约 2026-10-15；Anthropic 博客 10-16 解读。模型：**Claude Mythos 5** + 独立评估器闭环。
- **核心贡献：** 八项量子电路原语中七项显著降低 Toffoli×qubit；含使 divsteps 可逆的模逆新架构；Reed–Solomon / DQI 解码约 **12×** TQ 改进（相对既有基线）。
- **代码/数据：** 论文详述方法；博客称完整论文在 arXiv。
- **来源：** [Anthropic Blog](https://www.anthropic.com/research/designing-efficient-quantum-circuits) · [arXiv:2610.22367](https://arxiv.org/abs/2610.22367)

### 5. Google Research · 自主湿实验室构件（VERID / 适配体 / 蛋白结合剂，2026-10-16）
- **核心贡献：** VERID 数字孪生约束液面机器人；适配体三轮闭环提升命中；FAP 靶点上发现个位数 nM 级 de novo binder。

- **来源：** [Google Research Blog](https://research.google/blog/grounding-ai-agents-in-biological-reality-building-blocks-for-autonomous-wet-labs/)
