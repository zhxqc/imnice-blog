### 1. OpenAI · GPT-6.1 Terra：低价 computer use / 视觉推理（2026-10-26）
- **背景：** 屏幕理解→跨应用操作的单位成本，直接约束 Agent 编排与 Cursor / Codex 类工作流能否规模化。
- **发生了什么：** OpenAI 发布 GPT-6.1 Terra，定位快速高效的电脑操作与视觉推理，并强调更清晰自然的写作。ChatGPT Work / Codex 对 Plus、Pro、Enterprise、Edu 开放；API 模型名 `gpt-6.1-terra`。标准价 **$1 / $0.05 cached / $5** per MTok（相对 GPT-5.6 Terra 与 GPT-6.1 Sol **减半**）。官方测试（**厂商披露**）：Agents' Last Exam medium 较 5.6 Terra **+15pp**、约 **1/3** 成本，并称与 GPT-6 Astra 同级智能约 **1/10** 单价；任务完成速度较 Astra / 6.1 Sol **>3×**；Terminal-Bench 4.0 max **50.3%** vs 5.6 Terra **21.5%**。复杂编码仍建议 Sol / Astra。
- **为什么重要：** 把「高吞吐 Agent 干活」推到可算账的价格带；订阅侧同额度可跑更多任务。
- **来源：** [OpenAI 官方](https://openai.com/index/introducing-gpt-6-1-terra/) · [AIHOT 事件](https://aihot.news/story/30e9a1ca-aae1-410a-b1c6-53893df398db)

## 论文

1. **Phronix: The Capability-Centric Learning Paradigm for Agents**（首次提交，arXiv:2610.31789）— harness 学习从「用户写 skill」转向 predictor–validator–corrector，从执行中蒸馏可复用 MCP tool + skill；warm-start 首试复现约 **93–95%**（**论文自报**）。代码/数据未强调公开。[论文](https://arxiv.org/abs/2610.31789)

2. **Don’t Forget What You Just Learned: Self-Directed Repair…**（首次提交，arXiv:2610.31846）— **Self-Direction**：失败后自反思并蒸馏为轻量 LoRA「课程」；Qwen3.6-27B 上 GAIA **+17.0pp** 等（**论文自报**）。项目页 https://self-direction.github.io/ · [论文](https://arxiv.org/abs/2610.31846)

3. **SWE-Shift: Evaluating Coding Agents in Evolving Workspaces**（首次提交，arXiv:2610.32196）— Clean / Shifted 配对基准测中途环境变更；如 GPT-6 Astra Clean **67.35%** → Shifted **24.79%**（**论文自报**）。[论文](https://arxiv.org/abs/2610.32196)
