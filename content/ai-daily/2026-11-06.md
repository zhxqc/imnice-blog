## 模型 / 产品

### 1. Thinking Machines Lab · Inkling 2 Small：594B MoE / 17B 激活【头条·模型】
- **背景：** 开放权重赛道比拼的是「可部署激活参数 + 可复现训练配方 + 安全开权路径」，而不只是总参数口号。
- **发生了什么：** 官网（**2026-11-05**）发布第二代 **Inkling 2 Small**：Mixture-of-Experts，**594B** 总参数 / **17B** 激活；支持图像输入与 variable effort；自称 Artificial Analysis Intelligence Index **31**。预训练披露 H1 约 **8.4T** tokens（GB300 / 原生 NVFP4）等阶段；主 RL 约 **9** 天、**2048** GPU、**1700 万+** rollouts（厂商披露）。当前经 **Tinker** 提供（闭权）；称完成外部安全测试与红队后**下周**拟以 **Apache 2.0** 开放完整权重。
- **为什么重要：** 把「安全路径开权」做成可跟踪时间表；对开源权重与企业微调（Tinker）两边都有直接入口。基准数字均为厂商/第三方快照，需独立复核。
- **来源：** [Thinking Machines · Inkling 2 Small](https://thinkingmachines.ai/news/inkling-2-small/)

### 2. Cursor · Build Live Apps：描述即可构建并部署在线应用【头条·竞品】
- **背景：** Agent 降低了写代码成本，但大量内部工具仍停在 localhost；「从 IDE 到可分享链接」是编码 Agent 产品化的下一跳。
- **发生了什么：** Cursor Changelog（**2026-11-05**）上线 Build Live Apps：启动云端 Agent 并明确要求构建应用后，可脚手架 Web 应用、按需起 **Postgres**、用 Cursor SSO 配身份验证、托管部署并生成可访问链接；发布前跑确定性 + Agent 安全检查（密钥泄露等），管理员可审应用与密钥、拦截/下架。支持从 Cursor Origin / GitHub 新仓或已有仓部署；GitLab 等「即将支持」。适用于所有启用 cloud agents 的付费计划。
- **为什么重要：** 竞品优先关注项——把 Agent 从「改代码」推到「交付可运行内部产品」；对标无代码/低代码与云 IDE 托管叙事。
- **来源：** [Cursor Changelog · Build Live Apps](https://cursor.com/changelog/build-live-apps)

### 3. OpenAI · GPT-6 Cyber 系统卡与正式产品说明【安全·模型】
- **背景：** 昨报已覆盖 cyber 模型驱动的 Linux LPE 流水线（948 等）；本窗新件是**系统卡 + 产品页**，给出对齐与越权边界评测数字。
- **发生了什么：** OpenAI（**2026-11-05**）发布 GPT-6 Cyber：面向授权安全研究的 GPT-6 Astra 变体，经 RL 训练复现崩溃、开发可用 exploit、搜代码库漏洞等；经 **Daybreak Red** 受限访问。系统卡要点（作者披露）：ExploitGym Honeypot **无**部署安全指令时越权利用率 **0.07%**（GPT-5.6 Sol **49.5%**，GPT-5.6 Cyber **5.51%**，Astra **0%**）；带指令时观测为 **0%**；Auto-Review 拒绝遵循违规率 **0%**（与 Astra 持平）。Preparedness：Cybersecurity **Critical**，生物/化学 **High**，AI Self-Improvement 低于 High。产品文另称 ExploitGym 约 **48.5%**（相对 GPT-5.6 Cyber **32.1%** 提升）等。
- **为什么重要：** 把「更强攻防能力」与「更守授权边界」写成可核对的系统卡；对 Daybreak 客户与防御方工具链选型有直接含义。流水线成本账本仍以昨报长文为准，本条不重复展开。
- **来源：** [OpenAI · GPT-6 Cyber](https://openai.com/index/introducing-gpt-6-cyber) · [System Card](https://deploymentsafety.openai.com/gpt-6-cyber)

### 4. World Labs · Frameboy：Atlas 实时探索（最高约 15 fps）【产品·世界模型】
- **背景：** 世界模型若只能「点生成、等几十秒」，交互形态仍是离线视频；实时相机控制才会接近游戏/影视/机器人仿真工作流。
- **发生了什么：** World Labs 博客（**2026-11-05**）发布研究预览 **Frameboy**：将高度优化的 **Atlas** 变体从云端 GPU 流式传到浏览器，用户控制相机时最高约 **15 fps**；并接入封闭测试中的 **Viewfinder**（先逐帧建场景再实时探索）。官方承认云端高性能 GPU 成本仍明显高于本地渲染。
- **为什么重要：** 把 Atlas 从「生成一段视频」推进到「可漫游的交互渲染」；李飞飞等转发带动体验入口。
- **来源：** [World Labs · Frameboy](https://www.worldlabs.ai/blog/atlas-realtime) · [Demo](https://frameboy.worldlabs.ai/)

### 5. OpenClaw · Multiplayer：多人共享同一 Agent【产品】
- **背景：** 每人各自 Agent、各自上下文，跨角色协作时会出现「传话筒丢上下文」。
- **发生了什么：** OpenClaw 基金会博客（**2026-11-05**）发布 **Multiplayer**：多台设备同时操作同一 Agent、共享上下文，经共享队列协调请求；演示含实时可见对方输入。项目自称 MIT、模型无关、可自部署（免费）。
- **为什么重要：** 把 Agent 产品问题从「单人生产力」拉回「组织协作」；开源可自托管降低试用门槛。
- **来源：** [OpenClaw · Multiplayer](https://openclaw.ai/blog/shattering-silos-with-openclaw-multiplayer)

### 4. Anthropic · 科学家如何使用 Claude（20.7 万会话）【研究】
- **背景：** AI 加速科学取决于「能力」与「真实采用任务」是否对齐。
- **发生了什么：** Anthropic Economics（**2026-11-05**）隐私保护分析约 **207,000** 条 Claude / Claude Code 科研会话：相对研究者人数，正式科学（CS/数学/统计）使用更高；任务上数据分析约占 Claude **1/3**、Claude Code 近一半，创意/假设生成与大量数据采集相对偏低。情景估算：现有能力广泛采用下部分领域产出可约 **2×**；若非物理步骤全自动化，高度认知领域可至约 **15×**（模型情景，非预测）。配套调研约 **40%** 活跃 AI 用户预期 2030 年前 AI 可独立完成完整研究项目。
- **为什么重要：** 把「实验室 Agent」叙事落到可聚合的采用数据；与 vault 科学应用形成「案例 vs 宏观」对照。
- **来源：** [Anthropic Research](https://www.anthropic.com/research/how-researchers-use-claude)

### 1. Agent Harness Awareness：把已验证遥测变成工具 Agent 的操作控制（arXiv:2611.05391）
- **核心贡献：** 指出工具描述不等于运行时健康；由宿主在关键动作前注入小份**已验证状态快照**，保留测量/执行权威。ToolRoute 消融称可大幅降低可观测策略后悔（作者披露）。
- **来源：** [arXiv:2611.05391](https://arxiv.org/abs/2611.05391)

### 2. SlackBench：真实仓库协作项目上的 Agent 评测（arXiv:2611.05512）
- **核心贡献：** 基于真实学术工程复现的隐私保护对话 + 演进决策 + GitHub/Docs，评异构来源搜索、拒答、总结与情境推断；称最强系统约 **80%**、多数低于 **66%**。
- **来源：** [arXiv:2611.05512](https://arxiv.org/abs/2611.05512)

### 3. Who May Overrule the Agent：LLM 评审制度中的证据门控管辖权（arXiv:2611.05390）
- **核心贡献：** 区分「宽泛否决」与仅在记录到约束违反后才允许替换的 **evidence gate**；表明接口设计改变评审行为但非模型无关保障。
- **来源：** [arXiv:2611.05390](https://arxiv.org/abs/2611.05390)

### 4. Grounded but Not Immune：Agent-as-a-judge 中的确认偏误（arXiv:2611.05662）
- **核心贡献：** 即使工具取证，一条虚假预审笔记仍可推翻至约 **40%** 正确裁决；失败模式分过度信任 / 幻觉 / 调查不足。
- **来源：** [arXiv:2611.05662](https://arxiv.org/abs/2611.05662)

### 5. HarnessFlow：MCTS 引导的 Agent harness 优化（arXiv:2611.06254）
- **核心贡献：** 在固定模型与环境下搜索可执行 harness；有限预算下称优于初始 harness 与 Meta-Harness 基线。
- **来源：** [arXiv:2611.06254](https://arxiv.org/abs/2611.06254)

### 6. SafeStart：MoE 服务「减专家」加速的安全代价与缓解（arXiv:2611.06138）
- **核心贡献：** 实证减少每 token 专家可抬高越狱依从；提出提示阶段跑全专家、之后再减专家的 **SafeStart**，在保留大部分加速的同时压回拒绝率。
- **来源：** [arXiv:2611.06138](https://arxiv.org/abs/2611.06138)
