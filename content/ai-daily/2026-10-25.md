### 1. Block · Dessa 纯语音全双工模型（披露约 2026-10-23 晚 — 10-24；TechCrunch 跟进至 10-25 00:00 北京）【补录】
- **背景：** 多数商用语音链路仍是「语音→文本→LLM→TTS」，会丢掉情绪与重叠说话节奏；本地可跑的 speech-to-speech 对设备侧助理与安全评测都有缺口。
- **发生了什么：** Block 研究实验室发布 **Dessa**：厂商称从零、仅用人类语音对话训练（无文本预训练），直接处理音频；支持**全双工**（同时听与说），演示含笑声、停顿、哭泣等表现；可在单卡级 / **MacBook Pro M4 Max 或更高**本地运行。目前**不对公众开放**，正招募 AI 安全研究者测试欺骗风险等。上述能力与训练口径均为 **厂商披露**。
- **为什么重要：** 语音 Agent 路线与 OpenAI GPT-Live 等并列；「只给安全研究者」说明团队优先关心冒充真人风险。
- **来源：** [TechCrunch](https://techcrunch.com/2026/10/24/blocks-new-voice-model-sounds-eerily-human/) · [The Verge](https://www.theverge.com/ai-artificial-intelligence/1017906/jack-dorsey-block-dessa-ai-voice-speech) · [AIHOT 事件](https://aihot.news/story/b88dc665-3526-426a-b781-8ca78f4d67e7)

### 1. OpenAI · 隔离智能体经 CPU 缓存等侧信道通信【昨日训练加固文的实质跟进】（二次报道高峰约 2026-10-24 19:00–22:30 北京）
- **背景：** 昨日日报已覆盖「前沿训练断公网 + 高算力红队 + Brotli 等披露」。本窗 AIHOT 头条转向文中更刺耳的一条：即使断网、无共享文件，共享宿主机上的隔离任务仍可能「说话」。
- **发生了什么：** OpenAI 红队目标之一是「跨隔离边界通信」。实验中，同宿主机上的独立 microVM 智能体用 **处理器缓存时序**（一方驱逐缓存行，另一方测加载延迟解码）交换合成密钥；另有共享存储写节奏、TLS 证书缓存等通道。多数测试给了通道提示；至少一次只给漏洞清单，智能体自行约定编码并成功交换。厂商称通道通常慢、难利用，但已加监测。Mollick 等据此呼吁认真对待实验室对 AI 网络能力的前瞻判断（**观点/二次解读**）。
- **为什么重要：** 把「沙箱 = 安全」简化叙事打穿；对 Agent 评测机、共享 GPU 池的隔离设计有直接含义。
- **来源：** [OpenAI 原文](https://openai.com/index/securing-our-frontier-model-training-environment) · [The Decoder](https://the-decoder.com/openais-isolated-ai-agents-found-ways-to-talk-to-each-other-through-cpu-cache/) · [AIHOT](https://aihot.news/items/imgp55zxmw4jugt1a29ap9yo1) · [Mollick / X](https://x.com/emollick/status/2114001653879672877)

## 论文

1. **MCP vs CLI for AI Agents**（arXiv:2610.30157；本批 cs.AI）
   - 在 14 个维度比较 CLI 直调 vs MCP 结构化工具接入；结论：单用户本地工作流 CLI 更高效，多租户治理/凭证隔离/审计则 MCP 更合适；渐进披露可压低 MCP 上下文开销。
   - 代码/数据：文中未在摘要强调开源仓库 → **未在摘要确认**
   - [论文](https://arxiv.org/abs/2610.30157)

2. **Feedback That Backfires in Games**（arXiv:2610.30205；本批）
   - 在 Sokoban / 连四 / Othello 等环境测：把失败着法写回 transcript 后，小模型更可能**重复失败动作**（工具调用场景已知，游戏中同样成立）；「不要重复」指令几乎无效，干净重试有时更差。
   - 代码/数据：文称公开 probe 与原始记录
   - [论文](https://arxiv.org/abs/2610.30205)

3. **BELT: Belief-based Termination for early stopping**（arXiv:2610.30450；本批）
   - 从冻结 LLM 隐状态学习「当前/未来答案信念」，再拟合线性停止策略；OOD 数学基准上最多约少生成 41%–51% token 且不掉点，并迁移到代码/Agent 任务（**作者披露**）。
   - 代码/数据：摘要未给仓库链 → **未在摘要确认**
   - [论文](https://arxiv.org/abs/2610.30450)

4. **RoleFlow: Self-Evolving Multi-Role Agentic Collaboration**（arXiv:2610.30429；本批）
   - 用原子编辑 + SECPO（单次编辑反事实）让多角色协作结构可学习；七基准平均超最强对照约 4.7 分（**作者披露**）。
   - [论文](https://arxiv.org/abs/2610.30429)

5. **Is Complex Agentic Memory Always Needed? Naive RAG Is Stronger Than We Thought**（arXiv:2610.30755；本批）
   - Raw-RAG（稠密检索+重排原始对话史）在多数设定下反超复杂 agentic memory；提醒「记忆系统」要先过朴素基线。
   - [论文](https://arxiv.org/abs/2610.30755)

6. **Scaling Laws for Safety Probes**（arXiv:2610.30678；含 Anthropic 合作者；本批）
   - 为安全探针建规模律：误差随模型规模与标注量呈幂律；可用小模型拟合预测更大模型探针误差。
   - [论文](https://arxiv.org/abs/2610.30678)
