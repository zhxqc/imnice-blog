## 模型 / 产品

### 1. Anthropic · Claude Platform「message threads」公测：长跑 Agent 少传历史、降 TTFT【头条·产品】
- **背景：** 编码/计算机使用类 Agent 单会话可累积数十万至百万级 token；Messages API 每轮重传全历史会拉长首 token 时间（TTFT）。
- **发生了什么：** Claude 博客披露 **message threads** 公测：首轮带全量对话创建线程，之后只发增量消息 + 上一响应 ID；线程内存加密、约 **5 分钟**无请求后过期。多数 Claude Code 用户默认开启时，**500k–1M** token 请求中位 TTFT 约降 **35%**；token 计费不变（模型仍读全上下文）。已在原生 Claude Platform、AWS、Foundry、GCP（Anthropic 托管）可用。
- **为什么重要：** 直接压「长跑 Agent」的延迟税，是与 OpenAI/Cursor 等编码 Agent 体验竞争的基础设施层改进。
- **开放方式 / 规模 / 许可证：** Messages API `thread` 参数；公测；标准 Claude 计价与现有速率限制。上下文窗口等字段**官方未在该帖单独重列**。
- **来源：** [Claude · message threads](https://claude.com/blog/message-threads)

### 2. Cognition · Devin Enterprise「层级预算」：按公司组织树控 ACU【头条·竞品】
- **背景：** 企业部署编程 Agent 时常卡在「中心 IT 管不住部门用量、项目又需要临时加额度」。
- **发生了什么：** Cognition 官网博客（**2026-11-02**）推出 **hierarchical budgets**：账户根预算下最多 **三层** 子预算（部门/项目/用户），可设周期限额与临时加额；预算耗尽可中途停止会话；可与既有效率审批叠加。面向 Devin Enterprise，设置入口在 Enterprise Settings → Usage Policies → Budgets。
- **为什么重要：** 把编码 Agent 的成本控制做成与组织架构同构的产品能力，是 Cursor/Claude Code 企业侧对照项。
- **来源：** [Devin · Hierarchical budgets](https://devin.ai/blog/hierarchical-budgets)

### 3. OpenAI · ChatGPT 合并 Chat 与 Work 标签（定向灰度）
- **背景：** ChatGPT 桌面端同时存在 ChatGPT/Codex 分区，以及 Chat 与 Work 标签，路径易混淆。
- **发生了什么：** TechCrunch（**2026-11-02**）据用户邮件报道：OpenAI 将合并 Chat 与 Work，先向部分用户收集反馈；仍可在同一处带文件/插件做建站、演示文稿、网页操作等。**Codex 保持独立**；ChatGPT 与 Codex 将共用同一 Token 额度池——多数人无感，高用量者可能更频繁触达重置。
- **为什么重要：** 产品信息架构向「探索→交付」一体靠拢，并与 Anthropic 此前合并 chat/Cowork 的方向对照；共用额度会改变重度 Codex 用户的配额体感。
- **来源：** [TechCrunch](https://techcrunch.com/2026/11/02/openai-is-finally-merging-chatgpts-chat-and-work-tabs/)

### 4. OpenAI · 激活分类器（probes）：自 GPT-5.6 起的白盒安全监控层

- **为什么重要：** 把「防御纵深」推进到激活空间，是前沿模型上线安全栈的可复述技术细节。
- **来源：** [OpenAI Alignment](https://alignment.openai.com/training-activation-classifiers/)

## 论文

（口径：arXiv cs.AI / 相关 `new` 列表，本窗北京时间晨间抓取；2610.* 多为周末前后首次提交。）

### 1. CLR-Bench：自演化 Agent 能否学到隐性规则？（首次提交，arXiv:2610.40758）
- **核心贡献：** Curriculum of Latent Rules——每级增加一条隐藏的命名分组规则，用探针区分「真学会」与「背例外列表」。
- **关键实验：** 六种自演化方法在认证模型上几乎学不动（相对冻结 ≤+5 分；未见成员排除仅约 6–12%）；固定课表写明命名约定可 +14.5–16.5 分。更强模型上 ACE/Dynamic Cheatsheet 可仅凭反馈学到约 78% 准确率（作者披露）。
- **来源：** [arXiv:2610.40758](https://arxiv.org/abs/2610.40758)

### 2. AWM：无环境副本的 Agent 测试时扩展（首次提交，arXiv:2610.40927）
- **核心贡献：** 把下一观测预测改成多轮**只读安全查询** + 可执行计算的证据采集，从而在共享/持久环境无法克隆时仍做轨迹级 TTS。
- **关键实验：** 相对单次模拟平均约 **+40.07%**；相对训练世界模型基线约 **+12.36%**（τ-bench / AppWorld / OfficeBench，作者披露）。
- **来源：** [arXiv:2610.40927](https://arxiv.org/abs/2610.40927)

### 3. ReplayRCA：用反事实重放做 Agent 故障诊断与在线监督（首次提交，arXiv:2610.41025）
- **核心贡献：** 在选定步前恢复状态、替换动作后继续同一 Agent，以因果修复幅度相对安慰剂衡量事后尸检与在线一次监督。
- **关键实验：** 13 个前沿模型中最佳因果修复约 +51.3 分；事后排名与在线排名可显著脱钩（作者披露）。代码已释放。
- **来源：** [arXiv:2610.41025](https://arxiv.org/abs/2610.41025)

### 4. SafeWebWorld：网页世界模型的「安全充分性」不止于语义像样（首次提交，arXiv:2610.40798）
- **核心贡献：** 区分语义合理性与 EXECUTE/ASK/BLOCK 授权充分性；提出 SafeWebWorld 与 LAR。
- **关键实验：** SFT 可抬高证据保留却恶化授权决策（作者披露）——直接打脸「世界模型够用就安全」的简化叙事。
- **来源：** [arXiv:2610.40798](https://arxiv.org/abs/2610.40798)

### 5. Towards Portable Specification of the Agent Harness（首次提交，arXiv:2610.40917）
- **核心贡献：** 把 Agent **harness** 拆成 8 个功能组件，推动「同一模型换 harness 分数可差数倍」的可移植记录，便于评测治理与攻击面梳理。
- **来源：** [arXiv:2610.40917](https://arxiv.org/abs/2610.40917)
