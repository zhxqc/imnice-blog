## 模型 / 产品

### 1. Anthropic · Claude Platform「message threads」公测：长跑 Agent 少传历史、降 TTFT【头条·产品】
- **背景：** 编码/计算机使用类 Agent 单会话可累积数十万至百万级 token；Messages API 每轮重传全历史会拉长首 token 时间（TTFT）。
- **发生了什么：** Claude 博客披露 **message threads** 公测：首轮带全量对话创建线程，之后只发增量消息 + 上一响应 ID；线程内存加密、约 **5 分钟**无请求后过期。多数 Claude Code 用户默认开启时，**500k–1M** token 请求中位 TTFT 约降 **35%**；token 计费不变（模型仍读全上下文）。已在原生 Claude Platform、AWS、Foundry、GCP（Anthropic 托管）可用。
- **为什么重要：** 直接压「长跑 Agent」的延迟税，是与 OpenAI/Cursor 等编码 Agent 体验竞争的基础设施层改进。
- **开放方式 / 规模 / 许可证：** Messages API `thread` 参数；公测；标准 Claude 计价与现有速率限制。上下文窗口等字段**官方未在该帖单独重列**。
- **来源：** [Claude · message threads](https://claude.com/blog/message-threads)

### 2. OpenAI · ChatGPT 合并 Chat 与 Work 标签（定向灰度）
- **背景：** ChatGPT 桌面端同时存在 ChatGPT/Codex 分区，以及 Chat 与 Work 标签，路径易混淆。
- **发生了什么：** TechCrunch（**2026-11-02**）据用户邮件报道：OpenAI 将合并 Chat 与 Work，先向部分用户收集反馈；仍可在同一处带文件/插件做建站、演示文稿、网页操作等。**Codex 保持独立**；ChatGPT 与 Codex 将共用同一 Token 额度池——多数人无感，高用量者可能更频繁触达重置。
- **为什么重要：** 产品信息架构向「探索→交付」一体靠拢，并与 Anthropic 此前合并 chat/Cowork 的方向对照；共用额度会改变重度 Codex 用户的配额体感。
- **来源：** [TechCrunch](https://techcrunch.com/2026/11/02/openai-is-finally-merging-chatgpts-chat-and-work-tabs/)

### 3. OpenAI · 激活分类器（probes）：自 GPT-5.6 起的白盒安全监控层
- **背景：** 仅靠文本分类器监控提示/回复，在越狱与流式阻断上有局限。
- **发生了什么：** OpenAI Alignment 博客（标注 **2026-11-02**）说明：在最强模型内外部流量上部署基于残差流激活的 probes，逐 token 打分，可中途打断回复、阻断工具调用并交推理模型复审。实验称相对更大文本分类器对测试越狱更鲁棒，准确率随被监控模型能力上升，后训练检查点间迁移较好；但需为新基座重训，且只能检测可显式监督的已知违规类。文中提及部署起点为 **GPT-5.6**。
- **为什么重要：** 把「防御纵深」推进到激活空间，是前沿模型上线安全栈的可复述技术细节；也提示探针与基座权重耦合带来的运维成本。
- **来源：** [OpenAI Alignment](https://alignment.openai.com/training-activation-classifiers/)

## 论文

（口径：arXiv cs.AI recent，主要为 **2026-11-02** 周一 mailing；2610.* 编号多为周末前后首次提交。）

### 1. Latent Sparse Attention: Towards Subquadratic Ultra-Long Context Attention（首次提交，arXiv:2610.42147）
- **核心贡献：** 在学习的潜空间对 key 分层聚类，查询对聚类打分而非扫全 key，提出可蒸馏的 D-LSA 与可原生训练的 N-LSA，面向超长上下文稀疏注意力。
- **关键实验：** 在 GLM-5.3-Flash / Qwen-3.8-27B 等上评测至约 **10M** token；摘要称单层相对原稀疏/全注意力 prefill 最高约 **22.7× / 72.4×** 等加速，并保持相近精度（作者披露）。
- **代码/数据：** 指向 Prefrontal-AI 的 SGLang 集成与 latent-sparse-attention 仓库。
- **来源：** [arXiv:2610.42147](https://arxiv.org/abs/2610.42147)

### 2. TSBPO: Tree-Structured Branching for Policy Optimization in Interactive Language Agents（首次提交，arXiv:2610.41697）
- **核心贡献：** 用树结构采样—更新统一处理交互式语言 Agent 的分支采样、延迟反馈归属与多 token 动作损失聚合。
- **关键实验：** Qwen2.5-1.5B 上 ALFWorld 见/未见随机成功率约 **97.8% / 96.6%**；WebShop 500 目标上约 **81.1%** 每幕成功率（作者披露）。
- **代码/数据：** 摘要未强调完整开源；以论文为准。
- **来源：** [arXiv:2610.41697](https://arxiv.org/abs/2610.41697)

### 3. Evidence-Guided Recovery for AI Agents with Ambiguous Tool Outcomes and Partial Execution（首次提交，arXiv:2610.41453）
- **核心贡献：** 工具超时导致结果不明、部分已执行时，在固定提供商契约下做证据采集与继续执行的可审计恢复决策；区分私有目标达成与公开可证明完成。
- **关键实验：** 受控有限模型上规划建议相对证据提示，认证完成率约 **30/58 vs 9/58**（作者披露的注册实验框架）。
- **来源：** [arXiv:2610.41453](https://arxiv.org/abs/2610.41453)

### 4. Cross-Interface Authorization for AI Computer-Use Agents（首次提交，arXiv:2610.41397）
- **核心贡献：** 为 GUI/CLI/API/脚本/MCP 等多界面计算机使用 Agent 给出版本化 effect-surface 画像与路由绑定的 prepare/commit 授权协议，防旁路换路由洗白票据。
- **关键实验：** 参考画像 12 效应族 × 5 界面 × 60 路由；两套运行时映射共 **3464** 条轨迹等（作者披露）。
- **来源：** [arXiv:2610.41397](https://arxiv.org/abs/2610.41397)
