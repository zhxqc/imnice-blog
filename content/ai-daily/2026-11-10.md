## 论文

窗口对应 arXiv **周一 2026-11-09** 新清单（昨日早间仍显示周五清单，故相对昨日为新披露）。精选 4 篇；代码/数据以摘要自述为准。

### 1. CPU-ARC: Agentic Reasoning Caching for on-CPU Reasoning Reuse（首次出现于周一清单）
- **核心贡献：** 把 LLM 推理轨迹编译为可在 CPU 上复用的「agentic reasoning cache」，宣称在数学/科学任务上接近源模型，调用成本约低 **16–291×**。
- **与已有方法的区别：** 介于整段对话缓存与模块化缓存之间，强调可解释、可审查的代码化缓存。
- **关键实验：** MATH-500、AIME、GPQA 等；厂商式自报数字，需对照原文表格。
- **代码/数据：** 摘要未给出明确开源仓库声明 → **未披露/待核对**。
- **链接：** [arXiv:2611.09891](https://arxiv.org/abs/2611.09891)

### 2. Computer-Use Agents Are Embodied Generalists（首次出现于周一清单）
- **核心贡献：** 论证把具身任务暴露为「屏幕软件」后，同一 computer-use agent 可跨导航/分割等 ECCV workshop 竞赛获奖，无需为每赛定制 agent。
- **与已有方法的区别：** 把具身控制收束到截图 + 键鼠接口，主张具身 AI 可走 computer-use 同一条泛化路线。
- **关键实验：** 四个 ECCV 相关竞赛名次（含 OpenSUN3D 第一等）。
- **代码/数据：** 项目页 https://pranjal2041.github.io/cua-embodied ；完整可复现包以原文为准。
- **链接：** [arXiv:2611.09847](https://arxiv.org/abs/2611.09847)

### 3. Test-Time Compute Scales Better with Parallel Agent Teams（首次出现于周一清单）
- **核心贡献：** 在可用验证器的长程任务上，并行采样多个「小团队」优于大量独立 agent 或一个超大团队；27B 模型、100 agent 预算下在 12 任务中 10 个胜过并行单兵。
- **与已有方法的区别：** 把 best-of-N 用在团队级而非个体级，并用简单统计模型解释均值与方差权衡。
- **代码/数据：** 文首标注 Code → https://github.com/modal-projects/parallel-agent-teams-scaling
- **链接：** [arXiv:2611.09798](https://arxiv.org/abs/2611.09798)

### 4. Knowing When to Intervene: Causal Evaluation of AI Agents（首次出现于周一清单）
- **核心贡献：** 把部署期「是否审核 / 干预 agent」建成可识别的动态因果问题，给出 micro-randomized trial + blip / 策略增益估计，并在 τ-bench、ToolSandbox、ImpossibleBench 上示例。
- **为什么重要：** 把 agent 评测从静态榜单推进到「干预值不值」的决策科学。
- **代码/数据：** https://github.com/sawarniayush/agent-evaluation-sequential-randomization
- **链接：** [arXiv:2611.09792](https://arxiv.org/abs/2611.09792)
