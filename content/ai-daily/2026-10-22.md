## 行业 / 治理 / 安全

### 1. OpenAI · Patch the Planet：PHP2Shell 关键漏洞协调披露（2026-10-21）
- **背景：** 全球大量站点依赖 PHP；核心引擎内存安全问题一旦可远程利用，影响面极大。AI 加速找洞的同时，修复与协调窗口成为瓶颈。
- **发生了什么：** OpenAI 披露 **Patch the Planet** 计划下的协调披露：安全公司 **Calif** 用 **GPT-5.6 Sol** 发现 PHP 严重缺陷，**Wiz** 独立发现并报告；PHP 维护者主导修复与发布。漏洞编号 **CVE-2026-109618 / CVE-2026-109619**（合称 **PHP2Shell**），CVSS 约 **9.2**，可致无账号远程代码执行 / 内存泄露；影响追溯至约 PHP 5.4 / 自约 2004 年 PHP 5 起存在的叙述（多家报道），影响全球约 **70%** 网站。OpenAI 提供 Codex 技能与检测仓 **[php2shell-checker](https://github.com/openai/php2shell-checker)**；并描述五阶段全球响应框架，承诺约 **$1B** subsidized **Daybreak** 前线防御访问（**厂商披露**）；语境含与美政府多方协作。TechCrunch 等转述 NSA 建议无法立即修复的站点先下线。
- **为什么重要：** 把「AI 找洞 → 防御者窗口 → 协调披露」产品化为安全运营叙事；同等能力也可被攻击者武器化——官方亦承认这一点。运维侧应优先打补丁并自查版本。
- **来源：** [OpenAI 主源](https://openai.com/index/coordinated-disclosure-of-critical-vulnerabilities) · [Wiz Research](https://www.wiz.io/blog/php2shell-php-rce) · [TechCrunch](https://techcrunch.com/2026/10/21/php-armageddon-openai-googles-wiz-find-ancient-holes-panicking-the-internet/)

### 2. Wiz · LiteLLM PyPI 供应链攻击（恶意 v1.107.0，2026-10-21）
- **背景：** LiteLLM 是广泛使用的多模型 API 路由库；PyPI 供应链一旦被植入，凭据与密钥面临批量窃取风险。
- **发生了什么：** Wiz 披露约 **10-21 11:39 UTC** 恶意版本 **LiteLLM 1.107.0** 上传至 PyPI，随后被隔离；GHCR / Docker Hub 相关镜像标签亦曾被植入，约 **13:53 UTC** 移除。最近安全版本为 **v1.106.2**。
- **为什么重要：** Agent/网关栈对依赖版本敏感；应立即排查是否安装过 1.107.0，并锁定至安全版本、轮换可能泄露的密钥。
- **来源：** [Wiz Research](https://www.wiz.io/blog/litellm-compromised-steals-credentials)
