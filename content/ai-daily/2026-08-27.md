   - 核心贡献：把"世界模型"从视频域搬到代码域，用代码仓库作为世界演化规则载体，让 Agent 维持持久因果与连贯演化
   - 与已有方法的区别：视频世界模型只学观测结果，本作显式建模底层知识/规则/机制

   - 代码/数据：官方未披露

2. **Anchoring Bias in LLM-as-a-Judge Systems: Prior Scores Compromise Evaluation Independence**（首次提交，2026-08-26）
   - 核心贡献：证明 LLM 判官在锚定（带历史分数/修订框架）提示条件下，评分独立性被破坏，存在锚定偏差
   - 与已有方法的区别：此前 LLM-as-a-Judge 研究多聚焦一致性，本作首次系统检验"判断独立性"假设
   - 关键实验：三种提示条件对比（无元数据/修订框架/锚定元数据）
   - 代码/数据：官方未披露
   - [论文原文](https://arxiv.org/abs/2608.25869)

3. **Repair or Resample? Rethinking Failure Debugging in LLM Multi-Agent Systems**（首次提交，2026-08-26）
   - 核心贡献：质疑 MAS 失败调试"整轨重跑+重采样"的默认做法，追问其是否真能定位故障
   - 与已有方法的区别：从"重跑"转向"定向修复"视角
   - 关键实验：官方未披露
   - 代码/数据：官方未披露
   - [论文原文](https://arxiv.org/abs/2608.25920)

4. **Candidate supply and answer selection shape the value of LLM judging in multi-agent systems**（首次提交，2026-08-26）
   - 核心贡献：把多智能体推理拆成"候选生成→同侪通信→终选"流水线，指出 LLM 判官的价值取决于候选供给与答案选择规则
   - 与已有方法的区别：此前评估多智能体系统好坏只看最终答案，本作分离各环节贡献
   - 关键实验：官方未披露
