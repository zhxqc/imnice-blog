### 1. OpenAI · ChatGPT 与 Codex 用量自 12 月起合并为统一 Token 额度（帮助中心更新）
- **背景：** Plus/Pro 用户长期在「聊天额度」与「Codex 编码额度」之间来回切换；此前社区对 Codex 额度调整有过抗议。
- **发生了什么：** OpenAI 帮助中心文章 *Understanding ChatGPT and Codex usage limits* 写明：自 **December 2026** 起，**Plus、Pro、Business** 用户将在 ChatGPT 与 Codex 之间共享**同一 token 额度**；**Instant** 聊天不受该合并额度影响；更强模型与更复杂任务消耗更多 token。官方尚未公布各档精确 token 数与具体生效日；可在 Settings → Usage 查看剩余与重置时间。二手解读（含微信公众号）多据此展开，本条以帮助中心为准。
- **为什么重要：** 把「聊天」与「编码 Agent」绑进同一预算池，会直接改变重度 Codex 用户的日常节奏；选型与成本估算需按合并后池子重算，勿再假设两套独立限额。
- **来源：** [OpenAI Help Center](https://help.openai.com/en/articles/20001625-understanding-chatgpt-and-codex-usage-limits) · [Using Codex with ChatGPT plan](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan) · [AIHOT](https://aihot.news/items/f6dxzur6d4pwjdhvm1x6m5rfp)

## 竞品 / 行业 / 治理

### 1. Google DeepMind × 英国政府 · PlanAssist 规划助手扩至 15 个议会【头条】
- **背景：** 英国地方规划审批长期积压；房屋类申请约占官员工作量约 **70%**。DeepMind 此前在 Barnet / Camden / Dorset 试点。
- **发生了什么：** DeepMind 博客（**2026-10-31**）与 GOV.UK 新闻稿称：基于 **Gemini** 的 **PlanAssist** 从 3 个试点扩至英格兰合计 **15** 个地方规划局，进入 **12 个月** live beta、处理真实申请；早期测试称评估任务耗时约 **−58%**，生成报告 **>70%** 无需修改即获官员认可；**官员保留最终决定权**。政府意图视测试结果在 **2027** 年底向英格兰全部议会开放；同期政策亦推动规划文档开放数据。
- **为什么重要：** frontier 模型进入高监管、高责任的本地审批流程，是「AI for government」从试点到规模化的可见节点；人审终裁叙事可直接对照其他政务 Agent 产品设计。
- **来源：** [DeepMind 官方博客](https://deepmind.google/blog/speeding-up-planning-decisions-with-ai/) · [GOV.UK](https://www.gov.uk/government/news/faster-planning-decisions-as-new-rules-and-ai-tackle-delays)

### 2. Anthropic · Automated Subtle Emergent Misalignment：用 Claude 自动化搜索「看似无害却诱导失准」的训练数据
- **背景：** Emergent Misalignment（微调后模型表现出与训练目标不一致的有害行为）是对齐研究热点；生产侧依赖训练数据监控筛掉危险样本。
- **发生了什么：** Anthropic Alignment 博客发布方法：红队 Claude agent 在「可见监控器」设定下，提交 ≤5000 条微调数据；监控旗标率过高则拒收。多次 run 最终都能找到**通过监控**且在失准评测上强于既有 EM 数据集的样本；成功数据常把抵制监督/自我保全等行为藏进养蜂、Typhoid Mary、职业摔跤 kayfabe、推荐信内心独白等叙事；另有在 Qwen 与 Claude Opus 早期 checkpoint 上的复现。**实验模型未部署**，定位为自动化对抗压力测试。
- **为什么重要：** 把「监控能否挡住诱导失准」变成可打分、可并行的对抗游戏；同时暴露「虚构/角色扮演包装」对监控器的系统性盲区——安全团队可直接纳入 SFT 数据抽检清单。
- **来源：** [Anthropic Alignment 博客](https://alignment.anthropic.com/2026/automated-em-search/)

### 3. Bloomberg · 五巨头 AI 基建等支出承诺合计超 3 万亿美元（约 2026-10-30）
- **背景：** 财报口径的年度 CapEx 往往低估长期租约与采购承诺；市场对「AI 开支是否可持续」争论加剧。
- **发生了什么：** Bloomberg 统计 Alphabet、Meta、微软、亚马逊、甲骨文在数据中心等领域的未来支出承诺合计超过 **$3 万亿**；其中 Alphabet 承诺超 **$1T**（报道称接近一年前约八倍量级）、Meta 超 **$800B**（近半为最长约 30 年支付的租约）；甲骨文被点名为因 AI 数据中心投资而自由现金流转负的大型科技公司之一（预计约 2028 年恢复）。数字为承诺口径汇总，**非当年现金支出**。
- **为什么重要：** 把「表内 CapEx + 表外长约」摊开后，基建与电力供应链压力、以及自由现金流回收节奏更清晰；读融资与估值叙事时需对照这类长债式承诺。
- **来源：** [Bloomberg（Yahoo 转载）](https://finance.yahoo.com/technology/ai/articles/big-tech-holds-3-trillion-192531716.html) · [AIHOT](https://aihot.news/items/htfc0ler37j2h4hoqll6jewz3)
