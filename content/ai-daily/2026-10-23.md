## 模型 / 产品

### 1. OpenAI · Decisions API 正式 GA（2026-10-22）
- **背景：** Agent 热路径上大量「分类 / 路由 / 评分」只需有界答案，不必走通用 chat；低延迟小决策此前常挤在 Responses API 里。
- **发生了什么：** Decisions API 全面可用，基于 **GPT-6 Luna**；面向 predicate / choice / score 等有界决策，宣称相对 Responses API 上 Luna 可达约 **10×** 更快近实时决策。公开 beta 以来新增：原生 GPT-Live 集成、prompt caching、美/欧 inference residency、原生 JSON 输入、单请求最多 **400** 题。定价叙事：$0.10 / M input tokens，cached $0.01，无 output token 收费；ZDR 对合格客户可用。客户引用含 Box（~5× 路由）、Datadog（p95 ~40×）、Sierra（<280ms p95）等（**厂商披露**）。
- **为什么重要：** 把护栏与路由从通用 chat 拆成专用低延迟 API，直接影响 Agent 网关成本与语音交互路径；与昨日 Model Garden 分发叙事正交。
- **来源：** [OpenAI](https://openai.com/index/decisions-api/) · [开发者文档](https://developers.openai.com/api/docs/guides/decisions)

### 2. Uber · 全员部署 ChatGPT Work（>30,000，2026-10-22）
- **背景：** ChatGPT Work 是 ChatGPT Enterprise 内的多智能步知识工作 Agent；此前多为小范围试点。
- **发生了什么：** Uber 从约 1,000 人试点扩至全球 **>30,000** 员工；对接 Drive / Gmail / Calendar / Slack；默认能力叙述为 **GPT-6.1 Sol**；工程侧继续用 Codex。强调内部 skills 库、审批集成与培训。
- **为什么重要：** 超大规模「全员 Agent 平台」标杆案例；对 ChatGPT Work 产品化与企业采购有示范效应（**厂商联合披露，成效指标尚待后续**）。
- **来源：** [OpenAI](https://openai.com/index/uber-chatgpt-work-rollout) · [TechCrunch](https://techcrunch.com/2026/10/22/uber-puts-all-30000-employees-on-chatgpt-work/)

### 3. Claude · 网页/桌面/移动端下周默认 auto mode（Pro/Max/Team）
- **背景：** 日常 Agent 使用中，逐步批准工具调用会拖慢工作流，但全自动又放大误操作风险。
- **发生了什么：** Anthropic 称 Claude 网页/桌面/移动端将于下周对 **Pro / Max / Team** 默认开启 **auto mode**——不再逐步批准，由自动检查拦高风险操作，可切回手动；引用 Claude Code：独立分类器拦约 **89%** 危险命令（手动约 14%）（**厂商披露**）。**≠ Claude Duet**（昨日已主条目的主动式独立应用）。

## 行业 / 治理 / 安全

### 1. Anthropic · Agent Skills 捐赠给 AAIF（Linux Foundation，2026-10-22）
- **背景：** Agent Skills（`SKILL.md` 文件夹标准）自 2025-12 开源以来已成为跨平台事实标准；此前 Anthropic 已将 MCP 捐入同类治理轨道。
- **发生了什么：** 将 Agent Skills 捐赠给 **Agentic AI Foundation（AAIF）**；含名称/logo、GitHub org、agentskills.io。自称自开源以来 **70+** 平台集成（含 ChatGPT、Cursor、GitHub Copilot、VS Code），约 **100 万** skills 发布、**2.8 亿** 次安装（**厂商数字**）。Lead Maintainers：David Soria Parra、Mahesh Murag；提议版本化发布、正式提案流程与安全指引。Linux Foundation 同期宣布 AAIF 新增四项目（Agent Skills、Open Responses、OpenEnv、OpenSandbox）。
- **为什么重要：** skills 从 Anthropic 事实标准 → 中立基金会治理；与 MCP 同属「agent 互操作栈」开放化。
- **来源：** [Anthropic](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation) · [Linux Foundation](https://www.linuxfoundation.org/press/agentic-ai-foundation-announces-four-new-projects-agent-skills-open-responses-openenv-and-opensandbox)

### 2. Anthropic × Theorem · Claude 大规模形式化验证（2026-10-22）
- **背景：** 「LLM 找洞」已常见，但可机器检查的形式保证仍稀缺；OSS-Fuzz 覆盖的库量大、手工证明成本高。
- **发生了什么：** Frontier Red Team 与 Theorem 合作，用 Claude 在 **RISC-V 汇编级** 对 OSS-Fuzz 中 **123** 个开源库、**239** 个入口点写出约 **1.8 亿行** Rocq 证明；声称在给定假设下（单线程静态二进制、固定内存预算、<64MB 输入、建模 Linux 语义）可证明「不崩溃」类安全性质；过程中发现并修补多年未检出的 bug；公开部分证明与 Claude skill。明确限制：≠ 绝对无 bug；规格与机器语义仍是信任根。
- **为什么重要：** 把「找洞」叙事推进到「可机器检查的形式保证」；属研究发布而非产品 GA。
- **来源：** [Anthropic Research](https://www.anthropic.com/research/formal-verification) · [附录 PDF](https://www-cdn.anthropic.com/files/4zrzovbb/website/6867eadf760258fa8b42a504600cd3c036d16358.pdf)
