### 1. Google · Gemini 4 Argon 全球 GA
- **背景：** Gemini 4 系列面向复杂工程、企业知识工作与网络安全防御的长程工作流。
- **发生了什么：** 2026-10-13（约 UTC 16:00，北京时间 10-14 00:00）全球开放。开发者走 Gemini API 付费档 + AI Studio；Google AI Ultra 可在 Antigravity 试用；Pro/Ultra 用户可在 Gemini App 与 Search AI Mode 使用。统一上下文约 **1M** token；入门价 **$2 / $10** 每百万输入/输出 token（缓存输入 95% off），**2026-11-30** 后升至 $4 / $20。官方称内部 Antigravity 使 agentic 代码提交量 +35%、回滚约 -1/3；并给出 Chrome 大规模重构、ADK 性能优化、Fairwind 安全合作等案例。

- **来源：** [Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/) · [Model Card](https://deepmind.google/models/model-cards/gemini-4-argon/) · [AIHOT 条目](https://aihot.news/items/smxxtw5ca2c9jscojk4ppe5hf)

### 3. Anthropic · Scion：为 Agent 洪峰重做版本控制
- **背景：** Claude 推高 monorepo 日合并量，git 镜像与 clone 成为瓶颈。
- **发生了什么：** 工程博文披露：2026-05 约 **2,500** 次/日合并 → 2026-09 超 **30,000**；7 人团队约五个月自研 **Scion**，并上线评审面 Antique 等。设计原则：客户端始终在线、服务端算 blame/merge、稀疏/虚拟检出、无 packfile 维护。官方称相对旧 git 镜像舰队 CPU/内存约 **1/200**，CI 检出秒级且 CI CPU 回收约 **25%**。明确**不适合**作为通用 git 替代，也不会全面开源。
- **为什么重要：** 这是「Agent 写代码」对开发者基础设施的实证压力测试——工具链要为 swarm 重写，而不只是给 IDE 加聊窗。
- **来源：** [Anthropic Engineering](https://www.anthropic.com/engineering/redesigning-source-control)

## 论文

> 下列均标注为 arXiv **新提交**（cs.AI / cs.CL 新列表，约 10-13/14 窗口）；代码可用性以作者声明为准。

1. **ClawLoop: Self-Improving Agents via Harness-Native Training Loop**（首次提交，arXiv:2610.14118）  
   - **核心贡献：** 在 harness（文件/Shell 沙箱）内闭环：任务合成 → SFT/RL → 失败诊断反馈，**无外部更强教师模型**。  
   - **与已有方法区别：** 相对单次、依赖教师的 ClawGym 式管线，强调自举迭代。  
   - **关键实验：** Qwen3.6-27B 在 SkillsBench / Claw-Eval-Live / ClawGym-Bench 持续提升；合成任务迁移到 4B/9B 仍有收益（文内表格）。  
   - **代码/数据：** 文中指向配套资源；以 PDF/作者页为准。  
   - [论文](https://arxiv.org/abs/2610.14118)

2. **Harness²: Recursive Agent Harnessing for an Open World**（首次提交，arXiv:2610.14224 · Google Cloud AI Research）  
   - **核心贡献：** 任务级对比 Propose–Probe–Compose + harnessing 级经验库，在**无真值验证器**的开放任务流上递归改 harness（而非改权重）。  
   - **关键实验：** 单步即可提升 GLM-5 / Gemini 3.5 Flash；WorkBuddy-Bench 最高约 +11.5、LAB Partial 约 +11.8pp；增大并行预算继续涨。  
   - **代码/数据：** 宣称 [github.com/google-research/harness2](https://github.com/google-research/harness2)。  
   - [论文](https://arxiv.org/abs/2610.14224)

3. **The Silent Failures in Agentic Data Science**（首次提交，arXiv:2610.14115）  
   - **核心贡献：** 指出 Agent 数据科学评估只看准确率会掩盖泄漏、不当验证等方法失败；220 任务大规模失败模式 + 可控测试套件。  
   - **关键实验：** 多数方案至少含一类失败；数据泄漏与预测性能正相关。  
   - **代码/数据：** 文内称可复用测试套件（以作者发布为准）。  
   - [论文](https://arxiv.org/abs/2610.14115)

4. **Long-Horizon-Terminal-Bench 2.0**（首次提交，arXiv:2610.14146）  
   - **核心贡献：** 77 任务、最长约 3 小时、每 30 分钟检查点的**过程奖励**终端长程评测；相对纯终态二元通过率能保留中间进度信号。  
   - **关键实验：** 1,145 次评分；文内 GPT-6-astra dense mean 约 0.69 领先（**厂商/作者评测口径**）。  
   - [论文](https://arxiv.org/abs/2610.14146)

5. **Loose Lips: Understanding Privacy Leakage in Agentic Dialogue**（首次提交，arXiv:2610.14071）  
   - **核心贡献：** 基于 Contextual Integrity 的双 Agent 对话隐私泄漏基准；能力越强泄漏越多、思维链放大泄漏、多轮复合上升。  
   - **含义：** Agent 协作产品的隐私安全不能只靠拒答模板。  
   - [论文](https://arxiv.org/abs/2610.14071)
