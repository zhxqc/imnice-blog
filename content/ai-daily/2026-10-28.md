## 模型 / 产品

### 1. DeepMind · Genie 4：可交互世界仿真 + 原生音频（2026-10-27）
- **背景：** 世界模型要从「好看的生成视频」变成可操控、可改场景、可听可聊的仿真环境，才够支撑机器人训练与交互内容创作。
- **发生了什么：** Google DeepMind 发布 Genie 4。相对 Genie 3，强调照片级真实感、碰撞等物理与更自然的人物运动；可用键盘导航，并用自然语言在运行中改天气、加物体、调镜头；首次在实时世界模型中**原生生成环境音与可交互人物对话**。Gemini（含 Omni / Flash / Argon）可在环作引导 Agent，把多步事件拆解后注入世界。生成视频/音频含 **SynthID**。已向可信测试者开放研究预览，随后面向 Google AI Ultra（Project Genie）与 Gemini API / AI Studio 早期伙伴。官方自述长时一致性、物体永存、复杂物理与可读文字仍是限制。**非开源权重。**
- **为什么重要：** 把「实时交互世界」推到带音频的研究预览，并与 Gemini 规划闭环绑定，直接影响仿真数据与内容工具链选型。
- **来源：** [DeepMind 官方](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/) · [AIHOT](https://aihot.news/items/l74eacnb38ytvm5hm8om7h7cs)

### 2. OpenAI × Oracle · 企业应用进入 ChatGPT（2026-10-27）
- **背景：** 企业 Agent 的瓶颈往往不在聊天，而在 ERP/财务/采购数据与权限能否安全进对话工作区。

- **为什么重要：** 一手展示「ChatGPT 作为企业工作面」的落地形态，也把安全模型塞进 Oracle 安全产品线。
- **来源：** [OpenAI 官方](https://openai.com/index/oracle-apps-in-chatgpt) · [AIHOT](https://aihot.news/items/zbp5qzehshqnvgimabeu27cb1)

### 3. Liquid AI · LFM3 多模态 ~2B 开权重家族（2026-10-27）
- **背景：** 端侧与单卡微调场景需要统一骨干同时覆盖文本/视觉/音频，而不是拼一堆专用小模型。

- **为什么重要：** 与 Qwen/Gemma 小模型档正面竞争「专用智能 + 端侧」叙事。
- **来源：** [Liquid AI 官方](https://www.liquid.ai/blog/lfm3) · [AIHOT](https://aihot.news/items/vx4t4ldzajj3lhb8luhg9dy9s)

### 2. Anthropic · Agent 隐性倾向如何塑造专家判断（2026-10-27）
- **背景：** 「有人盯着」常被当作 Agent 治理答案，但专家是否真能抵抗模型默认选项很少被量化。
- **发生了什么：** 50 名有因果推断经验的分析师用 Claude Code（Opus 4.8）做统计分析；在不知情下用掷硬币随机设定 Agent 在四个分析决策上的倾向。分析师与 Agent 倾向一致约 **86%**（若无影响期望约 50%）；当 Agent 不同意时约 **60%** 仍改主意，同意时仅约 **6%** 改主意等（细节见原文）。
- **为什么重要：** 直接冲击企业 harness：需要可审计的默认选项披露、对抗性复核，而不是默认「专家在环=安全」。
- **来源：** [Anthropic 官方](https://www.anthropic.com/research/agents-judgment-calls) · [AIHOT](https://aihot.news/items/d0k8x9588e62wlqnfoq3bmtq0)

### 3. Anthropic × GSA · 政府购 Claude 享 40% 折扣（2026-10-27）

## 论文

1. **Memory Tax: Dissecting the Net Value of Agent Memory**（首次提交，arXiv:2610.34073）— 大规模评测发现许多专用记忆系统相对朴素 RAG **净值为负**；拆成 memory benefit 与 **memory tax**。代码/数据摘要未强调公开。[论文](https://arxiv.org/abs/2610.34073)

2. **Recursive Semantic Divergence for LLM Agent Consistency (RSD)**（首次提交，arXiv:2610.33012；作者称 NeurIPS 2026 录用）— 度量带工具 Agent 跨独立运行的行为一致性；代码开源。[代码](https://github.com/AgentConsistency/RSD-agent-consistency) · [论文](https://arxiv.org/abs/2610.33012)

3. **Build, Don't Play: AutoTavern**（首次提交，arXiv:2610.33845）— 自改进研究 Agent「造」Hearthstone 对战系统/基准而非只玩游戏。[代码](https://github.com/MCG-NJU/AutoTavern) · [论文](https://arxiv.org/abs/2610.33845)

4. **SciValidityBench: The Right Fact, the Wrong Decision**（首次提交，arXiv:2610.34767）— 科学 Agent 记忆基准：事实检索正确仍可能决策错误。[论文](https://arxiv.org/abs/2610.34767)

5. **AT-AT: Automatic Tool Optimization from Agent Traces**（首次提交，arXiv:2610.34679）— 从 Agent 轨迹自动优化工具定义/接口。[代码](https://github.com/Netflix-Skunkworks/agent-tool-opt-core) · [论文](https://arxiv.org/abs/2610.34679)

6. **Collective Emergent Alignment (REMAP)**（首次提交，arXiv:2610.34836）— 度量多智能体交互是否产生超出个体自精炼的参考对齐。[论文](https://arxiv.org/abs/2610.34836)

旁证（非 arXiv 主条目）：Ai2 **Old Ideas, Novel Problems** 揭示 LLM「新颖性裁判」不稳定——[AIHOT](https://aihot.news/items/p92a4pkxkheznj9nmt50o08l6)。
